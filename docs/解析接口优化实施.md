## 阶段目标与用户流程

用户粘贴分享链接，得到同一套结构的视频、画质、音轨、图集、实况图或分 P 信息，选择资源后下载；需要音视频合并、图集打包或未加密 HLS 合并时由服务器处理，展示真实进度并允许取消，不将错误页、播放清单或无音轨视频误作完整 MP4。

## 共享响应契约

保留 `/api/parse?url=...` 与外层 `code/msg/data/platform`。

- `type`：`video`、`image`、`live`；视频 `url`、图片 `images`、实况 `live_photo=[{image, video}]`。
- `author={name,id,avatar}`；`music={title,url}`；`duration` 统一毫秒，未知为 0。
- `video_backup` 是对象列表：`url/url_list/quality/width/height/data_size/fps/bit_rate/codec/format`；单位分别为字节、帧/秒、bit/s。不得将文件大小当码率。
- 分离流增加 `audio_url` 与 `requires_mux=true`，每个对应画质也带相同音轨 URL；不伪装成已包含声音的成片。
- B站 `parts=[{index,title,url,cid,duration}]`，`url` 为可交给同一解析入口的作品 `?p=N` 链接；只下载用户选择的分 P。
- `statistics` 只保留上游实际返回的数值；兼容既有顶层 `play_count`。
- 所有解析器输出统一结构；公开供方适配集中在 `media_normalizer.py`，原生解析器按同一契约直接产生结果。

## 范围与非目标

实现上述接口能力、元数据、分 P、实况、多画质、下载进度/取消、完整性检查、图集 ZIP、分离流合并及未加密 VOD HLS 下载。保持当前框架、页面入口和主题，不加入账号运营、私信、评论发布或绕过平台权限。

现有签名逻辑调整为指纹一致、支持列表匹配、会话获取去重及有效字段传递。FFmpeg 作为本地媒体合并工具，使用固定命令参数与本地已校验文件，不给它任意网络地址。

## 测试、安全与影响

- T2：供方路由、单位/结构归一化、原生页面与 API 提取、实况与分离流、下载代理及任务生命周期、错误和取消、网页交互。
- 网络只模拟最下游 HTTP 层；集成验证贯穿真实入口与格式化逻辑。真实公开视频只作少量解析和小文件/分段读取。
- 使用 Playwright 检查桌面、移动端、键盘与真实下载；沿用 `index.html` 现有下载行作为布局参考，不改顶部输入、主题或导航。
- 进度来自实际字节或阶段计数，未知总量不造百分比。任务隔离临时目录、并发/体积/时长/条目上限，取消终止网络和媒体子进程并清理。
- 每次跳转、HLS 子清单与分片都执行公网/已核验 CDN 规则；禁止凭据外泄、错误页下载、任意命令、任意文件读取或写入。

## 验证方法

运行 `python -m pytest -q` 和相关模块编译；检查真实小样本的解析响应与文件头、完整性。浏览器验证选择资源、取消、ZIP/合并、错误恢复和移动端布局。结构门禁只检查本文件是否自洽，功能结论必须来自上述实际执行证据。

## 停止条件与未验证

- 平台拒绝访问、作品已失效或当前权限未取得画质时，返回可解释结果或使用对应平台备用策略，不虚构成功。
- 未加密 VOD HLS 为处理范围；加密/DRM、直播无限清单明确拒绝，不进行解密或假装成片。
- 系统自动 Hook 的强制执行未验证；阶段结构检查和实际测试证据分别记录，不以结构检查代替功能验证。
