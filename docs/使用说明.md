# 短视频无水印解析 - 使用说明

## 快速启动

### Windows 一键启动

双击 `start.bat` 即可，脚本会自动安装依赖并启动服务。

### 手动启动

```bash
# 1. 安装依赖
pip install -r requirements.txt
pip install curl_cffi

# 2. 安装 Playwright 浏览器（首次需要）
playwright install chromium

# 3. 启动服务
python server.py
```

启动后访问 http://localhost:8848 即可看到 Web 界面。

## 使用方式

### Web 界面

打开 http://localhost:8848，粘贴视频分享链接，点击解析。

支持直接粘贴分享文案（会自动提取其中的 URL）。

解析完成后点击"下载"按钮，视频/音频会通过服务器代理下载，自动触发浏览器保存文件。
下载文件名自动使用视频标题。

抖音视频会单独显示原画或默认画质，再列出全部可用转码画质。每档展示分辨率、帧率、编码、码率和文件大小，并有独立下载按钮；同一分辨率的不同码率版本会分别保留。4K、2K、1080p 等标签按作品实际返回的分辨率显示，下载文件名包含标题及所选画质。

### API 调用

#### 解析视频

```
GET /api/parse?url=<视频链接>
```

示例：
```bash
curl "http://localhost:8848/api/parse?url=https://v.douyin.com/xxxxx"
```

返回：
```json
{
  "code": 200,
  "msg": "解析成功(免Cookie详情API)",
  "data": {
    "type": "video",
    "title": "视频标题",
    "url": "https://...无水印视频CDN直链...",
    "video_id": "v0200fg10000xxx",
    "original_url": "https://aweme.snssdk.com/aweme/v1/play/?video_id=v0200fg10000xxx&ratio=default&line=0",
    "quality": "original",
    "data_size": 3000000,
    "play_count": 12345,
    "video_backup": [
      {
        "quality": "normal_1080_0",
        "url": "https://...转码CDN直链...",
        "url_list": ["https://...主CDN...", "https://...备用CDN..."],
        "width": 1920,
        "height": 1080,
        "data_size": 2000000,
        "fps": 30,
        "bit_rate": 2000000,
        "codec": "h264",
        "format": "mp4"
      }
    ],
    "cover": "封面图URL",
    "author": {"name": "作者", "id": "抖音号"},
    "music": {"title": "BGM名", "url": "音频URL"}
  },
  "platform": "douyin"
}
```

`url` 优先返回经 HEAD 验证的原画 CDN，验证失败时返回可用转码链接。`original_url` 是原画接口入口，`video_backup` 包含上游返回的全部可用转码档，按码率降序排列；网页列出全部具有独立链接的转码选项，不再截取前 5 档。

`data_size` 单位是字节，`bitrate` / 转码档的 `bit_rate` 单位是 bit/s，`fps` 是帧率。选择原画时，HEAD 无法提供的 `width`、`height`、`bitrate`、`fps` 使用 0 表示未知；转码档仍保留其实际参数。`play_count` 仅在精选页返回匹配作品的有效计数时提供，失败时省略，不填假 0。图集不查询播放量。

#### 代理下载

```
GET /api/download?url=<视频直链>&filename=<文件名>
```

解析返回的视频/音频 URL 受 CDN 防盗链保护（需要 Referer 头），浏览器无法直接访问。
此接口由服务器代理转发请求，流式返回文件内容，触发浏览器下载。

Web 界面的下载按钮已自动使用此接口，无需手动调用。

#### 服务状态

```
GET /api/status
```

返回字段说明：
- `cookie_status`: `auto_full`(含msToken) / `auto_partial`(基础Cookie) / `manual`(手动配置) / `none`(未获取)
- `cookie_configured`: 是否有可用 Cookie
- `browser_available`: Playwright 是否可用

#### 策略测试（调试用）

```
GET /api/test?aweme_id=<视频ID>
```

逐个测试所有解析策略，返回每个策略的成功/失败状态。
默认关闭，需要本地设置 `ENABLE_DEBUG_ENDPOINTS=1`；包含新的 `web_api_open` 免 Cookie 策略。

#### Swagger 文档

访问 http://localhost:8848/docs 查看交互式 API 文档。

## 各平台解析原理

### 抖音

1. **免 Cookie 详情** - 使用开放平台 Origin/Referer 请求作品详情，不发送 Cookie 和签名
2. **签名 API 直连** - 免 Cookie 失败时尝试 Cookie、设备指纹与 TLS 指纹模拟
3. **浏览器渲染拦截** - Playwright 无头浏览器拦截详情，与 API 共用画质格式化逻辑
4. **公开 API 兜底** - 依赖第三方服务

获取视频后，并行探测原画 CDN 与精选移动页播放量；原画或播放量不可用时，仍可返回已取得的转码视频。

### 小红书

- 解析分享链接（xhslink.com）的 302 重定向，获取含 `xsec_token` 的完整 URL
- 请求页面 HTML，提取 `window.__INITIAL_STATE__` 中嵌入的笔记数据
- 支持视频笔记（返回无水印 MP4 直链）和图文笔记（返回原图列表）
- 分享链接自带认证 token，无需额外 Cookie

### 快手

- 解析短链接（v.kuaishou.com）重定向获取 photo_id
- 调用移动端 REST API（chenzhongtech.com）获取视频信息
- 备用：页面 HTML 提取 `__APOLLO_STATE__` / `__NEXT_DATA__`
- 公开API兜底

## 无水印下载原理

### 抖音
通过 `video.play_addr.uri` 构造 `aweme.snssdk.com/aweme/v1/play/?video_id=...&ratio=default&line=0`，用 HEAD 跟踪重定向并验证最终媒体响应及体积。

`video.bit_rate[]` 是转码档，并不等于原画；返回其全部可用链接和备用地址、宽高、帧率、码率、大小与编码。原画探测失败时，从有链接的转码档中选择最高码率。

每次媒体跳转均检查目标地址。使用代理 Fake-IP DNS 时，仅 `aweme.snssdk.com`、`*.douyinvod.com`、`*.zjcdn.com` 的 HTTPS 默认端口支持 `198.18.0.0/15` 和 `2001:2::/48` 映射；其他非公网目标仍拒绝。

接口核验和限制见 [抖音解析接口.md](抖音解析接口.md)。画质取决于作品本身，不能保证每条作品有 4K。

### 小红书
- 视频：`note.video.media.stream.h264[0].masterUrl` 直接是无水印 MP4
- 图片：`note.imageList[].urlDefault` 直接是无水印原图
- CDN 域名：sns-video-*.xhscdn.com / sns-webpic-qc.xhscdn.com
- 实测下载速度：10 MB/s

### 快手
- 视频：API 返回的 `mainMvUrls[0].url` 直接是无水印 MP4
- 图集：`atlas.list[]` 拼接 CDN 域名即为无水印原图

## 反风控机制

### 设备指纹随机化

每次请求自动随机生成：
- Chrome 版本（120/123/124/131/136）
- 屏幕分辨率（1920x1080、2560x1440、1366x768 等）
- CPU 核心数、设备内存
- 网络参数（downlink、RTT）
- TLS 指纹（curl_cffi 模拟对应 Chrome 版本）

### Cookie 自动管理

- 首次请求自动通过 Playwright 无头浏览器访问抖音获取 Cookie
- 浏览器上下文随机化（UA、分辨率、时区）
- 模拟真实用户行为（鼠标移动、滚动）触发安全 SDK
- Cookie 缓存 30 分钟，过期自动刷新
- 缓存文件：`.douyin_cookies.json`（自动生成，无需手动配置）

## 常见问题

**Q: 解析失败怎么办？**
- 检查 `/api/status` 确认服务状态和 Cookie 状态
- 用 `/api/test?aweme_id=xxx` 逐策略排查
- 确认 Playwright 浏览器已安装：`playwright install chromium`

**Q: 签名API一直失败？**
- 删除 `.douyin_cookies.json` 让系统重新获取 Cookie
- 确认安装了 `curl_cffi`：`pip install curl_cffi`
- 检查日志中是否有 ImpersonateError（curl_cffi 版本过旧）

**Q: 点击下载没反应或很慢？**
- 正常情况下载速度 10-20 MB/s，大文件（300MB+）需要等待十几秒
- 如果长时间无反应，可能是视频链接已过期（有效期通常几分钟），重新解析即可
- 下载通过服务器代理转发，确保服务器带宽充足

**Q: 下载的视频有水印？**
- 系统默认从 `bit_rate` 取最高画质无水印链接，正常不会有水印
- 如果出现水印，删除 `.douyin_cookies.json` 重新获取 Cookie 后再试

**Q: 视频链接格式？**
- 支持完整链接和短链接
- 支持直接粘贴抖音分享文案（含文字+链接）

**Q: 首次解析很慢？**
- 优先使用免 Cookie 详情；该策略失败后才可能启动浏览器获取 Cookie 或渲染页面
- 原画 HEAD 和精选页查询并行执行，分别设置 8 秒超时；上游较慢时会等待后返回已有结果
