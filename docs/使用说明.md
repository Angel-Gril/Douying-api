# 使用说明

## 解析与选择资源

启动服务后打开本地页面，粘贴分享链接或含链接的文案，点击“解析”。

- 视频：先显示原画或默认画质，再列出实际取得的全部视频档位。
- 分离音轨：视频下载操作会创建合并任务；音轨也可单独下载。
- 分 P：选择分 P 后点击解析按钮，只处理选中的部分。
- 图集与实况：分别下载静态图片、动态视频，或将相关资源打包成 ZIP。

画质、时长、大小和统计均来自实际解析结果。参数未知时不补造；未返回媒体地址的候选画质不会显示为可下载项。

## 普通下载

页面显示实际接收字节数；已知总长度时显示比例。点击“取消”中止下载，错误或内容不完整时可以重新解析并重试。

页面内存下载限制为 256 MiB。超过上限时可交给浏览器管理进度和取消；支持文件选择器的浏览器可以选用“直接保存到磁盘”。服务端处理完成的文件也由浏览器下载列表管理最终保存。

## 解析接口

```text
GET /api/parse?url=<分享链接>
```

外层结果：

```json
{
  "code": 200,
  "msg": "解析成功",
  "platform": "bilibili",
  "data": {
    "type": "video",
    "title": "示例视频",
    "url": "解析得到的默认媒体地址",
    "duration": 12000,
    "author": {"name": "示例作者", "id": "123", "avatar": ""},
    "video_backup": [],
    "audio_backup": [],
    "parts": []
  }
}
```

`duration` 使用毫秒，`data_size` 使用字节，码率使用 bit/s。`video_backup` 中每档包含自身的媒体地址、备用地址和元数据。`requires_mux` 表示需要配合 `audio_url` 合并；`requires_concat` 表示需按 `segments` 拼接。图集使用 `images`，实况资源使用 `live_photo=[{image,video}]`。

## 流式代理

```text
GET /api/download?url=<解析返回的媒体地址>&filename=<文件名>
```

支持单段 Range 请求和 206 响应。只接受受支持媒体主机、服务端明确配置的附加主机或公网 IP 字面量，每一跳都重新校验。返回非媒体内容、错误字节范围或不完整文件时不会报告成功。

## 下载任务

```text
POST /api/download/jobs
Content-Type: application/json
```

请求的 `mode` 为以下一种：

| mode | 请求资源 | 结果 |
|---|---|---|
| `zip` | `urls` 数组 | 图集或实况资源 ZIP |
| `mux` | `url` 与 `audio_url` | 含视频和音频的 MP4 |
| `concat` | 顺序排列的 `urls` 数组 | 拼接后的 MP4 |
| `hls` | `url` | 未加密点播清单合并后的 MP4 |

`filename` 为结果文件名。所有 URL 均应取自解析结果，不传本地路径。

创建返回 `data.id`。使用 `GET /api/download/jobs/{id}` 查询状态：`queued`、`downloading`、`processing`、`completed`、`failed`、`cancelled`。进度字段为 `downloaded_bytes`、`completed_items`、`total_items`，阶段描述在 `stage`。

完成后响应提供 `download_url`，指向 `GET /api/download/jobs/{id}/file`。处理中可调用 `DELETE /api/download/jobs/{id}` 取消；失败不会提供文件下载地址。

每进程最多 3 个活动任务、20 个保留任务，普通打包/拼接最多 100 个资源，HLS 最多 500 个分片，单任务上限 4 GiB 和 15 分钟。完成文件保留 10 分钟；处理任务采用进程内状态，运行时使用单 worker。

仅处理有结束标记的未加密点播 HLS。加密、DRM、无限直播清单或未验证的嵌套清单会被拒绝。

## 状态与开发排查

`GET /api/status` 返回服务状态、已实现的平台、下载能力和会话缓存状态。状态查询不主动刷新会话。`expired` 表示自动缓存已过期。

本地开发需要逐策略排查时，可启用配置示例中的调试选项，使用 `/api/test` 或 `/api/debug`。页面“原始数据”展示本次统一解析结果。
