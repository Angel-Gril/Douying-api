# 部署与运行

## 环境和安装

需要 Python 3.9+、可用的临时磁盘空间，以及能访问支持平台作品和媒体地址的网络。浏览器备用策略需要 Chromium；音视频合并使用依赖提供的本地 FFmpeg，也可用 `FFMPEG_PATH` 指定程序。

保留整个项目的 Python 模块、`index.html` 和依赖文件。不要仅上传入口脚本；解析器和下载任务模块都由入口导入。

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium
```

Linux 首次安装浏览器可执行 `playwright install --with-deps chromium`。运行参数以 `.env.example` 为模板，本地保存为 `.env`；会话缓存、日志、运行配置和下载产物不进入版本库。

## 启动与进程模型

```bash
uvicorn server:app --host 127.0.0.1 --port 8848 --workers 1
```

必须使用单 worker。下载任务的状态、取消事件和临时目录记录位于当前进程内；多 worker 会使后续查询或文件请求落到没有该任务状态的进程。当前实现不支持跨进程或跨实例共享任务。

页面入口为 `http://localhost:8848`，接口文档为 `/docs`，运行状态为 `/api/status`。状态查询只读取缓存和运行信息，不启动浏览器刷新会话。

服务管理器应使用项目虚拟环境中的 `uvicorn`，将工作目录设为项目根目录，并确保运行账户可写系统临时目录。普通停止会取消活动任务、终止媒体处理并清理临时文件；进程重启后任务不恢复，需重新发起。

## 反向代理

代理应关闭响应缓冲，并允许长时间的流式响应。以下配置中的端口与启动命令保持一致：

```nginx
location / {
    proxy_pass http://127.0.0.1:8848;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_buffering off;
    proxy_read_timeout 960s;
    proxy_send_timeout 960s;
}
```

普通下载透传有效的 Range / 206 响应。下载任务在创建后轮询状态，完成后由同源文件接口交给浏览器。反向代理须同时转发解析、普通下载、任务查询、取消和文件下载接口。

## 资源和网络边界

- 每进程最多 3 个活动任务、20 个保留记录；单任务下载上限 4 GiB，执行上限 15 分钟。
- ZIP 和多段拼接最多 100 个输入；HLS 最多 500 个分片。完成文件保留 10 分钟，预留相应临时磁盘空间。
- 下载服务器带宽随实际媒体流量消耗；大文件合并还需要本地输入和输出文件空间。
- 媒体域名和每次跳转均由服务器验证。附加主机只接受服务端配置，不由网页请求扩展。
- 媒体处理只读取已下载的本地文件。加密清单、无限直播及伪装清单明确拒绝。
- 本轮未加入账户体系。对外访问范围、连接数及请求频率由部署环境控制；诊断接口保持默认关闭。

## 开发验收

```bash
pip install -r requirements-dev.txt
playwright install chromium
python -m pytest -q
python -m compileall -q server.py douyin_parser.py bilibili_parser.py platform_parsers.py media_normalizer.py public_api.py media_downloads.py
```

启动后检查 `/api/status` 和页面，再验证作品解析、选择画质、普通下载、合并任务、取消和错误恢复。测试覆盖及本轮实站验证记录见 [解析原理与开发测试](解析原理与开发测试.md)。本轮未执行服务器部署。
