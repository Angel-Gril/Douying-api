# 短视频无水印解析 - 部署指南

## 环境要求

- Python 3.9+
- 1GB+ 内存（Playwright 浏览器需要）
- Linux / Windows Server 均可
- 需要能访问抖音 CDN（douyinvod.com）的网络环境

## 方案一：直接部署（推荐小规模）

### 1. 上传代码

```bash
# 服务器上
mkdir -p /opt/video-parser
cd /opt/video-parser

# 上传以下文件：
# server.py, browser_parser.py, cookie_manager.py,
# abogus.py, xbogus.py, index.html, requirements.txt
```

### 2. 安装依赖

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
pip install curl_cffi

# 安装 Playwright 浏览器
playwright install chromium
playwright install-deps  # Linux 需要安装系统依赖
```

### 3. 配置 systemd 服务

创建 `/etc/systemd/system/video-parser.service`：

```ini
[Unit]
Description=Video Parser Service
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/opt/video-parser
ExecStart=/opt/video-parser/venv/bin/uvicorn server:app --host 0.0.0.0 --port 8848 --workers 2
Restart=always
RestartSec=5
Environment=PYTHONUNBUFFERED=1

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl enable video-parser
systemctl start video-parser
```

### 4. Nginx 反向代理

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 代理下载接口需要较长超时和大 body 限制
    client_max_body_size 0;

    location / {
        proxy_pass http://127.0.0.1:8848;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 300s;
        proxy_send_timeout 300s;
        proxy_buffering off;  # 流式下载必须关闭缓冲
    }
}
```

```bash
nginx -t && systemctl reload nginx
```

### 5. HTTPS（可选但推荐）

```bash
apt install certbot python3-certbot-nginx
certbot --nginx -d your-domain.com
```

## 方案二：Docker 部署（推荐生产环境）

### Dockerfile

在项目根目录创建 `Dockerfile`：

```dockerfile
FROM python:3.11-slim

WORKDIR /app

# 系统依赖（Playwright 需要）
RUN apt-get update && apt-get install -y \
    libnss3 libatk1.0-0 libatk-bridge2.0-0 libcups2 \
    libdrm2 libxkbcommon0 libxcomposite1 libxdamage1 \
    libxrandr2 libgbm1 libpango-1.0-0 libcairo2 \
    libasound2 libxshmfence1 \
    && rm -rf /var/lib/apt/lists/*

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt curl_cffi \
    && playwright install chromium

COPY . .

EXPOSE 8848

CMD ["uvicorn", "server:app", "--host", "0.0.0.0", "--port", "8848", "--workers", "2"]
```

### docker-compose.yml

```yaml
version: "3.8"

services:
  video-parser:
    build: .
    ports:
      - "8848:8848"
    restart: always
    volumes:
      - cookie-cache:/app
    environment:
      - PYTHONUNBUFFERED=1
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8848/api/status"]
      interval: 30s
      timeout: 5s
      retries: 3

volumes:
  cookie-cache:
```

```bash
docker compose up -d --build
```

## 方案三：宝塔面板部署

适合不熟悉命令行的用户。

1. 宝塔安装 Python 项目管理器

## 性能调优

### Worker 数量

```bash
# 推荐：CPU核心数 * 2 + 1（但浏览器解析吃内存，建议不超过4）
uvicorn server:app --workers 2
```

### 关闭浏览器策略（低内存服务器）

如果服务器内存 < 1GB，可以不安装 Playwright，系统会自动跳过浏览器策略，只用签名API + 公开API。

### 下载速度说明

系统从 API 响应的 `bit_rate` 数组中提取最高画质的 CDN 直链（douyinvod.com），
这些链接是抖音 CDN 针对请求方地理位置优化的节点，下载速度通常在 10-20 MB/s。

`/api/download` 接口是流式转发（服务器从 CDN 拉取后实时推给客户端），带宽消耗 = 用户下载速度。
如果多人同时下载大视频，确保服务器带宽充足。

### 请求限流（Nginx）

```nginx
# 在 http 块中
limit_req_zone $binary_remote_addr zone=parse:10m rate=10r/s;
limit_req_zone $binary_remote_addr zone=download:10m rate=3r/s;

# 在 location 块中
location /api/parse {
    limit_req zone=parse burst=20 nodelay;
    proxy_pass http://127.0.0.1:8000;
}

location /api/download {
    limit_req zone=download burst=5 nodelay;
    proxy_pass http://127.0.0.1:8000;
    proxy_buffering off;
    proxy_read_timeout 300s;
}
```

## 架构说明

```
用户浏览器
    │
    ├── GET /api/parse?url=xxx     → 解析视频/图文，返回元数据 + 无水印直链
    │       │
    │       ├── 抖音: 签名API → bit_rate[0] 最高画质CDN链接
    │       ├── 小红书: 页面HTML → __INITIAL_STATE__ 提取视频/图片URL
    │       ├── 快手: 移动端REST API → mainMvUrls 无水印视频
    │       └── 其他: bugpk公开API兜底
    │
    └── GET /api/download?url=xxx  → 服务器代理下载（流式转发）
            │
            └── 服务器带 Referer/UA 请求 CDN → 流式返回给浏览器
```

各平台 CDN 链接均有防盗链保护：
- 抖音 CDN（douyinvod.com）：需要 Referer + UA + 时效签名
- 小红书 CDN（xhscdn.com）：需要 sign 参数 + 时效
- 快手 CDN（kwaicdn.com）：需要合法 UA

因此浏览器无法直接访问，必须通过服务器代理转发。

### 无水印链接获取原理

**抖音：** API 返回的 `video.bit_rate` 数组包含多个画质版本，取 `bit_rate[0]` 即为最高画质原画版本。

**小红书：** 分享链接自带 `xsec_token`，页面 HTML 中 `__INITIAL_STATE__` 包含完整笔记数据，视频/图片 URL 直接是无水印版本。

**快手：** 移动端 REST API 返回的 `mainMvUrls` 直接是无水印 MP4 链接。

这比 `aweme.snssdk.com` 重定向方式更快更稳定（后者需要多次跳转，且分配的 CDN 节点可能不是最优的）。

## 安全建议

1. **不要暴露到公网不加限制** - 至少加 Nginx 限流或 IP 白名单
2. **定期更新依赖** - `pip install --upgrade -r requirements.txt curl_cffi`
3. **日志监控** - 关注 Cookie 获取失败频率，频繁失败说明 IP 可能被风控
4. **如需对外提供服务** - 建议加一层 API Key 鉴权，防止滥用
5. **代理下载接口** - 注意带宽消耗，大文件下载会占用服务器出口带宽
6. **Cookie 文件** - `.douyin_cookies.json` 包含会话信息，不要泄露
