技术架构说明
解析策略优先级:
1. 免 Cookie 详情 - 获取抖音作品信息和全部转码画质
2. 签名 API - 使用 Cookie 和设备指纹请求详情
3. 浏览器渲染 - 拦截详情响应或提取页面数据
4. 公开 API - 调用第三方解析服务作为兜底

抖音签名算法:
- X-Bogus: MD5(URL参数+UA) → RC4加密 → 自定义Base64
- a_bogus: SM3哈希 + RC4 + 浏览器指纹 (由bdms SDK生成)

无水印提取方法:
- 原画：使用 video_id 和 ratio=default 获取原画 CDN
- 转码：从 bit_rate 数组保留各画质的播放地址和参数
- 每一档画质均通过服务器代理下载

配置Cookie提升成功率:
使用 setup_cookie.py 保存 Cookie，或在启动环境中设置 DOUYIN_COOKIE
